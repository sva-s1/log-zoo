# CSV (Comma-Separated Values) Log Samples

This directory contains log samples in **CSV format**. CSV is a widely-used structured data format that represents tabular data using comma-separated values, making it easily parseable by spreadsheet applications, databases, and log analysis tools.

## About CSV Logs

CSV format is commonly used for:
- **Structured log exports** from security devices, applications, and systems
- **Report generation** from log management platforms
- **Data interchange** between different logging systems
- **Bulk log analysis** in spreadsheet applications or data analysis tools

### CSV Format Characteristics

- **Delimiter**: Typically uses commas (`,`) to separate fields, though other delimiters like semicolons (`;`) or tabs may be used
- **Headers**: Often includes a header row defining column names
- **Quoting**: Text fields containing commas, quotes, or newlines are typically enclosed in double quotes
- **Escaping**: Double quotes within quoted fields are escaped by doubling them (`""`)

## Common CSV Log Sources

CSV logs are frequently generated by:

- **Security Information and Event Management (SIEM)** systems
- **Network monitoring tools** and traffic analyzers
- **Application performance monitoring** platforms
- **Database audit logs** and query logs
- **Web server access logs** (when exported from log analysis tools)
- **Firewall and intrusion detection systems** (export formats)
- **Cloud service logs** (AWS CloudTrail, Azure Activity Logs, etc.)

## Sample CSV Log Structure

A typical CSV log might look like this:

```csv
timestamp,source_ip,destination_ip,port,protocol,action,bytes_sent,bytes_received
2025-07-25 08:00:01,192.168.1.100,10.0.0.50,443,TCP,ALLOW,1024,2048
2025-07-25 08:00:02,192.168.1.101,10.0.0.51,80,TCP,DENY,512,0
2025-07-25 08:00:03,192.168.1.102,10.0.0.52,22,TCP,ALLOW,256,1024
```

## Parsing Considerations

When working with CSV logs:

1. **Header Detection**: Check if the first row contains column headers
2. **Delimiter Identification**: Confirm the actual delimiter used (comma, semicolon, tab, etc.)
3. **Quote Handling**: Properly handle quoted fields that may contain the delimiter character
4. **Data Types**: Convert string values to appropriate data types (timestamps, numbers, etc.)
5. **Encoding**: Be aware of character encoding (UTF-8, ASCII, etc.)
6. **Empty Fields**: Handle missing or empty values appropriately
7. **Line Endings**: Account for different line ending formats (CRLF, LF)

## Transport Methods

CSV logs are typically:
- **Exported** from log management systems as files
- **Generated** by scheduled reports or batch processes
- **Transferred** via file sharing protocols (FTP, SFTP, HTTP)
- **Streamed** through data pipelines or ETL processes
- **Stored** in cloud storage services for bulk processing

## Contributing

When adding new CSV samples to this directory:

1. **Sanitize data** - Remove or anonymize sensitive information
2. **Include headers** - Ensure CSV files have descriptive column headers when possible
3. **Document source** - Include information about the originating system or application
4. **Validate format** - Ensure proper CSV formatting and escaping
5. **Follow naming conventions** - Use descriptive filenames that indicate the log source and type
